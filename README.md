# Bibliothèque du Manager

Douze livres de management en cartes mentales interactives et en lectures d'environ 45 minutes.
Chaque lecteur crée un compte gratuit (e-mail et mot de passe) et retrouve ses livres lus,
sa position de lecture et ses marque-pages sur tous ses appareils.

- Site : GitHub Pages (`index.html`)
- Comptes et progression : Supabase (table `reading_progress`, protégée par des règles RLS)
- Les copies PDF ajoutées par un lecteur restent sur son appareil.
